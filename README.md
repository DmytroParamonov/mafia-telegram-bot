# ☢️ STALKER: Мафія в Зоні

Telegram-бот, який повністю замінює ведучого в класичній «Мафії», але оформлює всю гру як ходку в Зону: збір біля багаття, ролі на ПДА, бандитська братва, нічні вилазки, сходка табору та таємне рішення сталкерів.

## Ролі

- ☢️ Вільний сталкер — вираховує бандитів на сходці.
- 🔪 Бандит — уночі разом із братвою обирає ціль.
- 👑 Авторитет — ватажок бандитів, додатково шукає Розвідника.
- 🔎 Розвідник — уночі дізнається, чи пов'язаний обраний гравець із бандитами.
- 💉 Польовий медик — може врятувати одного живого гравця, включно із собою.

Усередині рушія збережені старі технічні ідентифікатори ролей, тому наявна база та вже зіграні партії не ламаються.

## Що вміє бот

- Збір групи в загальному Telegram-чаті.
- Вхід через особистий чат із ботом, щоб секретні ролі й дії гарантовано приходили на ПДА.
- Перевірка готовності всіх учасників перед виходом у Зону.
- Автоматична роздача ролей і баланс для 5–20 гравців.
- Ніч у Зоні: наліт бандитів, лікування медика, розвідка та пошук Розвідника Авторитетом.
- Атмосферні випадкові події Зони, які не впливають на баланс гри.
- Кілька різних описів нічних смертей, порятунку медиком і тихих ночей.
- Світанок, сходка біля багаття та таємне голосування.
- Переголосування у разі нічиєї.
- Автоматична перевірка перемоги сталкерів або бандитів.
- Налаштування спецролей і показу ролей вибулих.
- Таймери фаз і відновлення партії після перезапуску.
- Кілька груп можуть грати одночасно.
- Статистика `/stats`.
- Docker і GitHub Actions.

## Швидкий запуск

Найпростіший варіант на macOS/Linux:

```bash
chmod +x run.sh
./run.sh
```

Під час першого запуску скрипт попросить токен від `@BotFather`, створить локальний `.env` і запустить проєкт через Docker або Python 3.12+.

## Як грати

1. Додай бота до групового чату.
2. Напиши `/stalker`.
3. Гравці тиснуть «🔥 Сісти до багаття» й відкривають особистий чат із ботом.
4. Старший групи налаштовує ролі й тисне «🚪 Вирушаємо» після набору щонайменше 5 людей.
5. Кожен учасник підтверджує готовність у ПДА.
6. Коли всі готові, електронний ведучий сам проводить усю ходку.

## Команди

- `/start` — відкрити ПДА / приєднатися до групи за запрошенням.
- `/stalker` — зібрати нову ходку в груповому чаті.
- `/mafia` — старий прихований псевдонім для сумісності.
- `/help` — правила.
- `/stats` — особиста статистика.

## Важливо про Telegram

Telegram не дозволяє боту першим починати особистий діалог із користувачем. Тому приєднання відбувається через deep-link в особистий чат бота. Після `/start` бот уже може надсилати гравцю роль, нічні дії, перевірку готовності та таємний вибір.
