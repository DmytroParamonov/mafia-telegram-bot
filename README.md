## 🎮 Що це

**«Мафія в Зоні»** — Telegram-гра на **5–10 людей**, де бот повністю бере на себе роль ведучого класичної соціальної дедукції.

Гравці збираються в груповому чаті, а секретна частина проходить у приватному чаті з ботом — особистому **ПДА**. Там приходять ролі, персональні арти, нічні дії, таємні голосування, канал Бандитів, останнє слово та службові повідомлення.

Поза ходками цей самий приватний чат стає **постійним ПДА-профілем**: у ньому є схрон з хабаром, звання, магазин, редактор оформлення, колекція трофеїв, вітрина та статистика.

> Хабар дає прогрес, косметику й колекціонування, але **ніколи не купує переваги всередині Мафії**.

## 🚀 Локальний запуск

Після завантаження свіжого ZIP з гілки **`main`** робоча папка має називатися приблизно:

```text
mafia-telegram-bot-main
```

На macOS:

```bash
cd ~/Downloads/mafia-telegram-bot-main
chmod +x run.sh
./run.sh
```

Щоб зупинити бота: **Ctrl+C**.

# 💰 Економіка хабару

## Два рівні грошей

### 🎒 Хабар ходки

Тимчасовий хабар конкретної партії. Саме ним гравець ризикує в Зоні.

На початку справжньої ходки кожен отримує:

```text
+20 хабару
```

Він ще **не лежить у постійному схроні**.

### 📦 Схрон

Постійний баланс акаунта між іграми.

Після легітимно завершеної партії хабар, який вдалося винести, переходить у схрон. Хабар зі схрону **ніколи не крадеться Бандитами**.

---

## 💵 За що дається хабар

| Подія | Нагорода |
|---|---:|
| 🎮 Участь у справжній ходці | +20 |
| 🏆 Перемога своєї сторони | +50 |
| ❤️ Дожив до завершення | +15 |
| 🔎 Розвідник реально знайшов загрозу | +15, максимум 2 рази |
| 💉 Лікар реально врятував атакованого | +20, максимум 2 рази |
| 🎯 Голос за загрозу, яку реально вигнали | +10, максимум 3 рази |
| 🧛 Успішне вбивство Кровососа | +20, максимум 3 рази |

На створення нового хабару діє обмеження **150 за одну ходку на одного гравця**. Це захищає економіку від нескінченних довгих партій і багів.

---

## 🔪 Пограбування Бандитами

При успішному нічному вбивстві Бандити забирають частину **тимчасового хабару ходки** жертви:

- `50%` від поточного рюкзака;
- але не більше **30 хабару з однієї жертви**;
- якщо Бандитів двоє — здобич ділиться між ними;
- постійний **Схрон не чіпається ніколи**;
- якщо Лікар врятував ціль — пограбування не відбувається.

Це переказ уже існуючого хабару, а не друк нових грошей.

---

## 🛡 Захист від фарму

Автоматичні нагороди не видаються за `/test`, скасоване лобі або достроково обірвану ходку.

Для банкінгу хабару гра повинна:

- мати не менше **5 реальних гравців**;
- завершитися реальною умовою перемоги;
- мати хоча б одне справжнє голосування.

Кожне нарахування має унікальний запис, тому повторне виконання обробника або перезапуск бота не повинні дублювати нагороду.

# 🛡 Адмін-економіка

Усі гроші зберігаються в SQLite, а **кожна зміна балансу записується окремою транзакцією**.

Тобто баланс не редагується «магічно»: можна побачити, звідки прийшов хабар — ходка, магазин або ручне адмін-нарахування.

## Як увімкнути адмінку

1. Запусти нову версію бота.
2. У приватному чаті напиши:

```text
/id
```

3. Бот покаже твій Telegram ID.
4. Додай його в `.env`:

```env
ADMIN_USER_IDS=123456789
```

Для кількох адміністраторів:

```env
ADMIN_USER_IDS=123456789,987654321
```

5. Перезапусти бота.

Після цього в твоєму `/start` з'явиться **`🛡 Адмін-панель`**.

### Ручне нарахування

Найзручніше — відповісти командою на повідомлення гравця:

```text
/habar +500 Турнір
```

Або вказати користувача:

```text
/habar @username +500 Турнір
/habar 123456789 -100 Корекція
```

У адмін-панелі також є швидкі кнопки `+100`, `+500`, `+1000`, `−100`.

Кожна така операція потрапляє в журнал.

## 🗄 База економіки

Нові таблиці створюються автоматично в поточній SQLite-базі під час запуску. Окремо вручну створювати базу не треба.

Основні сутності:

| Таблиця | Що зберігає |
|---|---|

| `game_economy` | тимчасовий хабар конкретної ходки |
| `game_habar_events` | ігрові нагороди й пограбування без дублювання |
| `shop_items` | каталог магазину |
| `user_inventory` | куплені предмети |
| `trophy_catalog` | каталог трофеїв |
| `user_trophies` | колекції гравців |
| `user_showcase` | трофеї, виставлені в ПДА |

## 🔪 Особливі механіки

### 📻 Канал братви

Якщо Бандитів двоє, перші **30 секунд ночі** вони можуть писати боту в особисті повідомлення. ПДА передає текст тільки живій братві.

Для успішної атаки всі живі Бандити повинні вибрати одну й ту саму ціль.

### 💉 Лікар — Доктор Кайманов

Може рятувати іншого живого учасника або себе.

### 🧛 Кровосос

Третя сторона з окремою нічною атакою. Уночі потенційно можуть загинути дві різні цілі.

### ☠️ Мертві мовчать

Якщо бот має право **обмежувати учасників**, вибулий автоматично отримує мут до завершення партії. Після фіналу бот повертає право писати.

### 📟 Останнє слово

Після денного вигнання гравець має **30 секунд** на одне власне текстове повідомлення через ПДА.

---

## ☢️ Жива Зона

Режим уже існує як окремий перемикач у лобі, але **поточна розробка економіки не змінює його механіку**.

Наявні ефекти залишаються такими, як були:

- 🌫 Затяжна ніч: `+30 сек.` ночі;
- 🧠 Пси-спалах: `−30 сек.` ночі;
- ☢️ Наближається викид: `−60 сек.` обговорення;
- 🧠 Пси-перешкоди: `−30 сек.` обговорення;
- 📟 Збій мережі ПДА: `−30 сек.` голосування.
