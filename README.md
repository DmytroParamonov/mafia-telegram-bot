# ☢️ STALKER: Мафия в Зоне

Telegram-бот, который полностью заменяет ведущего в классической «Мафии», но оформляет всю игру как ходку в Зону: сбор у костра, роли на ПДА, бандитская братва, ночные вылазки, сходка лагеря и тайное решение сталкеров.

## Роли

- ☢️ Вольный сталкер — вычисляет бандитов на сходке.
- 🔪 Бандит — ночью вместе с братвой выбирает цель.
- 👑 Авторитет — главарь бандитов, дополнительно ищет Разведчика.
- 🔎 Разведчик — ночью узнаёт, связан ли выбранный игрок с бандитами.
- 💉 Полевой медик — может спасти одного живого игрока, включая себя.

Внутри движка сохранены старые технические идентификаторы ролей, поэтому существующая база и уже сыгранные партии не ломаются.

## Что умеет бот

- Сбор группы в общем Telegram-чате.
- Вход через личный чат с ботом, чтобы секретные роли и действия гарантированно приходили на ПДА игрока.
- Автоматическая раздача ролей и баланс для 5–20 игроков.
- Ночь в Зоне: налёт бандитов, лечение медика, разведка и поиск Разведчика Авторитетом.
- Рассвет, сходка у костра и тайное голосование.
- Переголосование при ничьей.
- Автоматическая проверка победы сталкеров или бандитов.
- Настройки спецролей и раскрытия ролей выбывших.
- Таймеры фаз и восстановление партии после перезапуска.
- Несколько групп могут играть одновременно.
- Статистика `/stats`.
- Docker и GitHub Actions.

## Быстрый запуск

Самый простой вариант на macOS/Linux:

```bash
chmod +x run.sh
./run.sh
```

На первом запуске скрипт попросит токен от `@BotFather`, создаст локальный `.env` и запустит проект через Docker либо Python 3.12+.

## Как играть

1. Добавь бота в групповой чат.
2. Напиши `/stalker`.
3. Игроки жмут «🔥 Присесть к костру» и открывают личный чат с ботом.
4. Старший группы настраивает состав ролей и жмёт «🚪 Выдвигаемся» после набора минимум 5 человек.
5. Дальше электронный ведущий сам проводит всю ходку.

## Команды

- `/start` — открыть ПДА / войти в группу по приглашению.
- `/stalker` — собрать новую ходку в групповом чате.
- `/mafia` — скрытый старый алиас для совместимости.
- `/help` — правила.
- `/stats` — личная статистика.

## Важно про Telegram

Telegram не разрешает боту первым начинать личный диалог с пользователем. Поэтому вступление идёт через deep-link в личку бота. После `/start` бот уже может присылать игроку роль, ночные действия и тайный выбор.
