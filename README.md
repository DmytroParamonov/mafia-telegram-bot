# 🎭 Mafia Telegram Bot

Telegram-бот, который полностью заменяет ведущего в игре «Мафия»: собирает лобби в групповом чате, приватно раздаёт роли, проводит ночь/день, принимает тайные действия и голоса, определяет победителя и хранит состояние игры в SQLite.

## Что уже заложено в проект

- Лобби в групповом чате: создать игру, войти, выйти, закрыть набор.
- Вход через личку бота по deep-link, чтобы бот гарантированно мог присылать секретные сообщения.
- Роли: Мирный, Мафия, Дон, Комиссар, Доктор.
- Мафия знает союзников; остальные видят только свою роль.
- Ночь: голос мафии за убийство, лечение Доктора, проверка Комиссара, поиск Комиссара Доном.
- День: результат ночи, обсуждение, тайное голосование в личке.
- Переголосование при ничьей; повторная ничья оставляет всех в живых.
- Автоматическая проверка победы после ночи и дневного изгнания.
- Настройки лобби: включение/выключение спецролей и раскрытия роли погибшего.
- Таймеры фаз и восстановление после перезапуска: дедлайны лежат в БД, а не только в памяти.
- Несколько групп могут играть одновременно.
- Статистика `/stats`.
- Docker и GitHub Actions.

## Быстрый запуск

1. Создай бота через `@BotFather` и получи токен.
2. Скопируй `.env.example` в `.env`.
3. Впиши `BOT_TOKEN=...`.
4. Запусти:

```bash
docker compose up -d --build
```

Либо без Docker:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
python -m app.main
```

## Как играть

1. Добавь бота в групповой чат.
2. Напиши `/mafia`.
3. Игроки нажимают «➕ Войти в игру» и переходят в личку бота.
4. Хост нажимает «🚀 Игроки набраны» после набора минимум 5 человек.
5. Дальше бот ведёт игру сам.

## Команды

- `/start` — запуск/вход в лобби по приглашению.
- `/mafia` — создать лобби в группе.
- `/help` — краткая помощь.
- `/stats` — личная статистика.

## Важно про Telegram

Telegram не разрешает боту первым начинать личный диалог с пользователем. Поэтому вступление в игру специально идёт через deep-link в личку бота: после `/start` бот уже может отправлять игроку роль, ночные действия и голосование.
