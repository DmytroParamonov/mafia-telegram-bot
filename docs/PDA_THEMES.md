# 🎨 Візуальні теми ПДА

ПДА-профіль рендериться ботом як справжня PNG-картка з даними конкретного гравця.

Код сам малює демонстраційний шаблон для кожної теми, тому система працює навіть без жодного локального фонового файла.

## Як замінити шаблон своїм артом

Після першого запуску бот автоматично створить:

```text
data/pda_themes/
├── pda_standard/
├── pda_military/
├── pda_dark/
├── pda_red/
├── pda_field/
├── pda_black/
└── pda_legend/
```

У потрібну папку поклади файл з назвою `bg`:

```text
data/pda_themes/pda_dark/bg.png
```

Підтримуються:

- `bg.png`
- `bg.jpg`
- `bg.jpeg`
- `bg.webp`

Після перезапуску/наступного рендера бот автоматично використає локальний фон замість програмного шаблону.

## Рекомендований розмір

```text
1200 × 760 px
```

Якщо зображення має інший розмір, бот сам обрізає та масштабує його до формату картки.

## Що бот наносить поверх фону

- ім'я гравця;
- PDA ID / Telegram ID;
- звання;
- косметичний титул;
- поточний схрон;
- хабар, зароблений за весь час;
- кількість різних трофеїв;
- прогрес до наступного звання;
- трофеї з активної вітрини;
- назву активного скіна;
- статус `ZONE NET // ONLINE`.

Тому фон краще робити атмосферним, але не забивати дрібним текстом центральні блоки.

## Теми та ключі

| Ключ | Тема |
|---|---|
| `pda_standard` | 📟 Стандартний ПДА |
| `pda_military` | 🪖 Військовий ПДА |
| `pda_dark` | 🌑 Темний ПДА / BLACK-LINK |
| `pda_red` | 🔴 Аварійний ПДА |
| `pda_field` | ☢️ Польовий ПДА |
| `pda_black` | ⬛ Чорний ПДА / BLACK PROTOCOL |
| `pda_legend` | ⭐ ПДА Легенди |

## GitHub

Авторські фони не зберігаються у репозиторії. `data/pda_themes/**/*.(png|jpg|jpeg|webp)` ігноруються `.gitignore`, так само як рольові арти та картинки дня/ночі.
