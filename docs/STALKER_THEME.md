# ☢️ STALKER theme

Игровой движок сохраняет внутренние идентификаторы классической «Мафии» для совместимости с существующей SQLite-базой, но весь пользовательский интерфейс оформлен как «Мафия в Зоне».

## Роли

- Мирный житель → ☢️ Вольный сталкер
- Мафия → 🔪 Бандит
- Дон → 👑 Авторитет
- Комиссар → 🔎 Разведчик
- Доктор → 💉 Полевой медик

## Атмосфера

Лобби — сбор у костра, личные сообщения — ПДА, ночь проходит в Зоне, дневное обсуждение — сходка у костра, голосование — решение лагеря. Побеждают либо сталкеры, зачистившие лагерь от бандитов, либо бандиты, получившие контроль над лагерем.

Основная команда: `/stalker`. Старая `/mafia` оставлена скрытым алиасом для обратной совместимости.
